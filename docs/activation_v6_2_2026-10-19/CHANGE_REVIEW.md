# V6.2 change review

Baseline: the source-matched V6.1 release `bdbdfcf68f4e0d0afba8fe3dfb60c9087283897a081425b35e75d664e1e22f95`, 3,195 passing tests, 54 preserved databases. V6.2 retains the original strategy manifest and `signal_brain.py`.

- `DurableHistory` persists genuinely observed post-close WebSocket candles. The engine and history validator exclude a live update received before logical close even after the local clock advances. Existing bounded genuine REST backfill, duplicate/conflict handling and stale gates remain.
- `SerializedStreamMarket` uses the existing method-resolution order to serialize REST fallbacks while cached stream reads avoid the REST lock. This removes a cache/REST lock inversion with WebSocket persistence. A targeted test checks both lock boundaries.
- `history-review` now retains raw candle wire events alongside durable facts and availability diagnostics. The independent all-ten probe compares three REST snapshots, two separately acknowledged raw WebSocket connections and the existing local history.
- A distinct finite trading-isolation policy binds the exact historical row, consumed marker, original nonce store, raw PAR/PAS readbacks and bounded fill query. It never changes the historical outcome. The separate interactive acceptance binds a particular PAS mandate, source, host and expiry. Every signed-boundary authorization revalidates it; new UNKNOWNs, exposure, mutation, revocation and expiration fail closed. Native proof and session acceptance remain independent.
- PAS mandate ceilings are at most 60 minutes, 20,000 USDP bankroll, 1,000 per entry and 2,000 cumulative. Existing two-attempt, one-position, twelve-action, 1x CROSS and price/fee/nonce/ownership constraints remain. One shared offline fixture's previous 60-minute-plus-one-second interval was tightened to exactly 60 minutes; no production exception was added.
- A separate PAS risk overlay uses allocated bankroll as denominator. Actual owned fill PnL, fees and funding plus reported unrealized PnL and a separately labeled exit-cost reserve enforce an intracycle session loss stop. Initial-bankroll loss and sampled peak drawdown use the tighter bound. The sampled intracycle peak also survives a completed close. The stop latches durably and reserves a single authorized exit attempt; a rejected or partial close never causes a blind retry.
- Unsigned native plans expose one-lot residual notional and required genuine receipt fields. They retain the signed-entry block for unsupported minimum behavior. No PAS qualification executor, approval, order or fill is fabricated.

Fifty-six new offline tests cover acceptance and receipt tampering, wrong scope/source/host, expiry/revocation, new UNKNOWN/live exposure, risk ceilings, fee-inclusive marked loss, one-attempt loss-stop behavior, post-close provenance, persistence/conflicts and cache/REST lock ordering. Synthetic tests never certify PAS. Two development regressions were intentionally interrupted for the concurrency and drawdown carry-through corrections and retained separately; only the final complete source-matched receipt can qualify the release.
