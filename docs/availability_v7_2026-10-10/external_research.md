# External data research — 10 October 2026

This is a research proposal and an isolated comparison tool. Production stays `PAR_NATIVE_ONLY`; external live signals remain unapproved. Documentation checks below establish advertised interfaces, not measured latency, uptime, entitlement or trading advantage. Raw captures and comparison receipts are separate evidence.

## Competition permission

The current [official FAQ](https://perpetual-alpha26.github.io/faq/) permits external data in practice and scoring. It encourages disclosure of sources and processing in the submitted code and PDF report. It does not list provider-specific licenses or authorize redistribution. It says detailed reproducibility requirements are still being finalized. These statements match the permission described in V7; the retrieved page provides no revision history proving that all rules are unchanged.

The [participant guide](https://perpetual-alpha26.github.io/docs/) still selects testnet `par`, USDPR collateral, prefixed coin queries and dex-scoped account/market queries. External signals do not replace venue prices, liquidity, account reconciliation, fees or funding. The order book determines execution; external candles cannot make an unavailable native book tradable. Existing production locks remain authoritative.

Issuer evidence separately confirms [EWY](https://www.ishares.com/us/products/239681/ishares-msci-south-korea-capped-etf) and [EWJ](https://www.ishares.com/us/products/239665/ishares-msci-japan-etf) are iShares ETFs listed on NYSE Arca. [NYSE hours](https://www.nyse.com/trade/trading-information?force_isolation=true) list a 9:30–16:00 Eastern core session. Extended-hours changes do not make a weekend ETF series a continuous par series. A session calendar must use exchange timezone and daylight-saving/holiday rules rather than a fixed UTC offset.

[ICE Brent specifications](https://www.ice.com/products/219/Brent-Crude-Futures) describe a 1,000-barrel contract and monthly expiry mechanics. This requires explicit conversion of contract counts if one studies barrel-weighted volume; the implemented research capture performs no such conversion or roll stitching. [CME gold specifications](https://www.cmegroup.com/markets/metals/precious/gold.contractSpecs.html) are the primary contract source to verify before using a gold futures proxy. [S&P's index page](https://www.spglobal.com/spdji/en/indices/equity/sp-500/) identifies the index benchmark; it does not turn index levels into traded shares.

No provider/source adjustment, corporate-action policy or continuous-futures roll rule has been silently applied. API timestamps are converted only from documented units to UTC minute starts. Price inversion/rescaling and manufactured volume are absent. A schema-valid reference candle is validated **for recording**, not validated for strategy equivalence.

## Architecture and research boundaries

`MarketDataSource` returns immutable `ResearchCandle` records with source, source symbol, interval, start/end, OHLCV, volume/price units, observation time and validation status. A source symbol cannot start with `par:`. `AssetMapping` separately names the native reference and rejects unreviewed identity, currency/price-unit mismatch, wrong FX direction and unsuitable volume before VWAP research.

A native-cache insertion rejects research records at the existing native-identity validator. Production imports no external adapter. The native production configuration rejects external source modes and self-declared live approval. The provider class can request only public metadata/candles from a fixed mainnet `/info` endpoint; it has no signer, order/transfer method or accounting interface. Requests are bounded and use the existing rate manager; provider outage cannot alter native state.

The comparison joins only completed intervals whose **actual reception** precedes the comparison decision timestamp. Downloaded historical data can support a new current comparison; it cannot be relabeled as available at an old strategy decision. No provider outage is repaired with other-source bars inside native history.

For a future experiment A/B/C, require genuinely recorded decision-time datasets, reviewed instrument/volume units, complete UTC history and frozen-hash checks. Only then call the unchanged feature functions. Native quotes, depth, marks, funding/margin and actual fills still determine feasible execution. Price-basis limits require a separate reviewed decision; this task does not invent one. The research output has null trade-feasibility/P&L/fee/funding/outcome/signal-agreement fields when evidence is insufficient. It cannot promote itself.

The present capture is a small **as-of price comparison**, not an opportunity backtest. A profitable external strategy, improved signal availability, comparable VWAP, source reliability and licensing fitness are **NOT ENOUGH EVIDENCE** until those prerequisites are established. No jury score or profitability is inferred.
