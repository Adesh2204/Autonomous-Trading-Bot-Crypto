# Implementation scope and known limits

System A shares one native monitor between public feed and scanner clients. It observes decoded public responses and individual validated WS rows, records source reception separately from cache acceptance, and preserves the existing merge validator. No wire row enters the cache through the monitor. The health manager still owns quarantine and retry deadlines; the original 300-bar repair window and one worker remain. Optional retry hints require 20 live completed REST samples, exclude startup history, only increase an existing delay, and cannot exceed five minutes. Due symbols are ordered by age cohort, then missing cache count; all selected symbols remain in the worker batch. Client-level read deadlines, bounded retries, coalescing and safety reserves remain unchanged.

The latest expected 300-minute window is an observation view. Existing history eligibility can still use an older contiguous tail inside the unchanged two-minute freshness allowance. Full UTC scanner history is measured separately through the scanner client's actual request and validation rules. The monitor never substitutes its verdict for the scanner's authoritative decisions, volatility/spread tests or ranking.

REST/WS logical candle end is start + 60,000ms, while raw T may be close boundary minus 1ms. Source publication timestamps are not available. Measured delay is first completed **reception** minus logical close; network/polling effects cannot be separated. Startup intervals are left-censored; intervals still absent at observation end are right-censored. Small-sample quantiles are descriptive, not latency guarantees. An absent row in a covered response does not prove permanent absence or an exchange defect.

Detailed interval records retain up to 5,000 minutes, recent requests/recoveries retain 40 events per market, and the existing raw public audit retains its 256 MiB cap. Monitor state is deliberately not imported into the paper ledger or native truth. It restarts as a new observational segment; a historical publication delay is not reconstructed with a new reception time. Prior files and hashes stay preserved.

System B's library has no network-client imports, native-client imports, execution transport or account interface. The standalone public research collector supplies only allowlisted mainnet metadata/candle reads through a fixed info endpoint and established weighted budgeting. Research candles are immutable, source-named and cannot carry a par symbol. Research defaults off; no production source fallback exists. A reference identity in organizer documentation does not establish comparable volume or a safe price-basis threshold.
